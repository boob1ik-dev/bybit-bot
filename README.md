# Bybit-бот «правило 200 дней»

Раз в сутки после закрытия дневной свечи бот сравнивает вчерашнюю цену закрытия BTC со средней за 200 дней:

- цена **выше** средней — держит BTC (покупает на все USDT на счёте);
- цена **ниже** средней — держит USDT (продаёт весь BTC).

В большинстве дней ничего не происходит: в среднем бывает 7–8 сделок в год.

## Настройки (переменные окружения на Render)

| Переменная | Что значит | По умолчанию |
|---|---|---|
| `BYBIT_API_KEY`, `BYBIT_API_SECRET` | ключ субаккаунта: только торговля спотом, **без вывода** | — |
| `TESTNET` | `1` — тестовый счёт Bybit, `0` — реальный | `1` |
| `DRY_RUN` | `1` — только считает и пишет, ордеров не ставит; `0` — торгует | `1` |
| `SYMBOL` | торговая пара | `BTCUSDT` |
| `SMA_DAYS` | за сколько дней считается средняя | `200` |
| `TG_TOKEN`, `TG_CHAT_ID` | Telegram-уведомления (необязательно) | — |

Расписание на Render: `5 0 * * *` — каждый день в 00:05 UTC (02:05 по Израилю зимой, 03:05 летом).

## Порядок запуска

1. `TESTNET=1`, `DRY_RUN=1` — проверить, что бот видит цены и баланс.
2. `TESTNET=1`, `DRY_RUN=0` — 2–4 недели торговли тестовыми деньгами.
3. Новый ключ с реального субаккаунта, `TESTNET=0`, небольшая сумма.

Бот торгует **всем**, что лежит на счёте ключа. Поэтому используйте отдельный субаккаунт и кладите туда только ту сумму, которую отдаёте боту.
